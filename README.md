تحليل النتائج
خوارزميات O(N²) مثل Selection Sort وBubble Sort وInsertion Sort استغرقت وقتًا أطول عمومًا مع البيانات العشوائية والعكسية مقارنةً بخوارزميات O(N log N).
في البيانات المرتبة، كان Bubble Sort الأسرع بسبب استخدام شرط التوقف المبكر، بينما كان Insertion Sort سريعًا أيضًا.
في البيانات الجزئية، حققت Quick Sort أفضل زمن في هذه التجربة.
اختيار Pivot يؤثر على أداء Quick Sort؛ واستخدام العنصر الأوسط كمحور ساعد في تجنب التقسيمات السيئة في حالتي الترتيب والعكس في هذه التجربة. Java
